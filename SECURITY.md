# Security and privacy

Co&Co Sort works on people's private footage, so we take two kinds of problems seriously:

- anything that could delete, overwrite or corrupt a user's file
- anything that could move files outside the folder being sorted, or send file contents somewhere the user didn't expect

## Reporting

Please report these privately using GitHub's **Report a vulnerability** button on the Security tab of this repository, rather than in a public issue. We aim to reply within a week.

For ordinary bugs, use a normal issue.
